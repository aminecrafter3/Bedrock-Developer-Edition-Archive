# Bedrock Developer Edition Archive

This repository archives two versions of the Minecraft Bedrock Edition Developer/Debug build:

- **Beta 1.16.0.51** (`3849713`)
- **1.18.3004**

Downloads and installation instructions are available in the [Releases](../../releases) section. Both versions have been tested and confirmed to work on Windows 10.

These builds include features and tools not normally available in standard Minecraft Bedrock Edition, including:

- A working **F3 debug menu**
- **Ore UI documentation**
- Additional commands and developer tools

The goal of this repository is to preserve these lesser-known versions and make them easier to discover, install, and explore.
